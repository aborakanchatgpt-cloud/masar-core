# دليل تفعيل n8n المستضاف ذاتيًا (لأحمد)

n8n الآن مستضاف على نفس خادم مسار Core، على الرابط:

**https://n8n.62.238.117.20.sslip.io**

اتبع الخطوات بالترتيب:

## 1) إنشاء حساب المالك
افتح الرابط أعلاه لأول مرة، وستظهر صفحة إعداد المالك (owner setup) — أنشئ
الحساب بإيميلك وكلمة سر قوية. هذه الخطوة تُنفّذ مرة واحدة فقط.

## 2) استيراد سير العمل (Workflows) عبر Import from URL

كل سير عمل من n8n Cloud مُصدَّر مسبقًا وموجود جاهزًا في المستودع، مع فهرس كامل
بروابط الاستيراد المباشرة:

**[n8n/workflows/INDEX.md](https://github.com/aborakanchatgpt-cloud/masar-core/blob/main/n8n/workflows/INDEX.md)**

لكل سير عمل في الفهرس:
1. انسخ رابط "Import from URL" من الجدول.
2. في النسخة المستضافة ذاتيًا: Workflows ← الزر (⋯) أو New ← **Import from
   URL**، والصق الرابط.
3. ابدأ **بمجموعة "جسور" (Bridges)** أولًا (Core - Call، Core - Notify
   Admin/Customer، GitHub - Commit/Read File، HTTP - Probe)، ثم مجموعة
   "النظام القديم".
4. سير عمل واحد فقط (**Job Bot - Admin Assistant**) لم يُصدَّر تلقائيًا بسبب
   حجمه — صدّره يدويًا حسب الملاحظة الموجودة أمامه في الفهرس (Workflow ←
   Download من Cloud، ثم Import from file هنا).
5. بعض سير العمل يستدعي سير عمل آخر بمعرّفه الداخلي (Execute Workflow) —
   الفهرس يحدد أيها ويشرح كيفية إعادة الربط يدويًا بعد الاستيراد (القسم 4 في
   INDEX.md).

⚠️ **خطوة يدوية منفصلة — Data Tables**: لا يمكن تصديرها/استيرادها بنفس طريقة
سير العمل. الفهرس (القسم 3) يتضمن قائمة تحقق بكل جدول وأعمدته — أعد إنشاء بنية
كل جدول يدويًا في النسخة المستضافة ذاتيًا، ثم صدّر بياناته من n8n Cloud كملف
CSV واستورده.

## 3) إعادة إنشاء بيانات الاعتماد (Credentials)
بيانات الاعتماد لا تُنقل تلقائيًا — أعد إنشاءها يدويًا في النسخة الجديدة (أنت
تُدخل القيم بنفسك، لا تُشارك أو تُنسخ من أي مكان). أسماء الاعتمادات المطلوبة
لكل سير عمل مذكورة في عمود "الاعتمادات المطلوبة" داخل INDEX.md، وإجمالًا:

- Telegram (توكن البوت) — بأسماء: "Telegram account" و"Telegram Admin Bot"
- Gmail (OAuth)
- Anthropic (مفتاح API)
- Header Auth باسم **"Masar Core Admin Token"**
- Header Auth باسم **"Masar GitHub"**

## 4) وصول MCP (اختياري الآن)
موصل Claude **"Masar Core"** مفعّل بالفعل ويكتب/يقرأ من هذا المستودع مباشرة
عبر GitHub — لا تحتاج تفعيل MCP على مستوى نسخة n8n الذاتية لإتمام هذا التصدير
أو لتشغيل سير العمل. فعّل "Instance-level MCP" داخل n8n لاحقًا فقط إذا احتجت
أن يتحكم Claude مباشرة بسير عمل n8n (سرد/تشغيل) من نفس النسخة المستضافة ذاتيًا؛
هذه خطوة إضافية منفصلة وليست شرطًا لعمل النظام.

## 5) التبديل الفعلي (بعد التأكد من الاستيراد والاعتمادات)
حوّل المهام المجدولة في Claude لاستخدام الموصل الجديد (self-hosted)، واستمر
بالاحتفاظ بحساب n8n Cloud فعّالًا كخط رجوع حتى تتأكد من استقرار كل شيء لفترة
كافية.

## 6) ملاحظة أمنية
مفتاح تشفير n8n (`N8N_ENCRYPTION_KEY`) يُولّد تلقائيًا ويُحفظ داخل
`/opt/masar-core/.env` على الخادم — لا تشاركه مع أحد ولا ترفعه لأي مكان.
